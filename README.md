# 🍔 Burger Tests Project

Юнит-тесты для класса `Burger` с использованием JUnit 4 и Mockito. Включает параметризованные тесты и анализ покрытия кода через JaCoCo.

## 📋 Технический стек

| Компонент      | Версия               | Назначение                    |
|----------------|----------------------|-------------------------------|
| **Java**       | 11 (Corretto 11.0.26)| Базовый язык                  |
| **JUnit**      | 4.13.2               | Фреймворк для unit-тестов     |
| **Mockito**    | 3.12.4               | Мокирование зависимостей      |
| **JaCoCo**     | 0.8.7                | Анализ покрытия кода          |
| **Maven**      | 3.6+                 | Сборка проекта                |

## 🚀 Быстрый старт

### Требования
- **JDK 11** (рекомендуется [Amazon Corretto](https://aws.amazon.com/ru/corretto/))
- **Maven 3.6+**
- **IntelliJ IDEA** (рекомендуется)

# Сборка и запуск тестов
mvn clean test
